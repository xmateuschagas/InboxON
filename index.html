Testar com a API da sua VPS

Baixe index.html e servidor.py na mesma pasta. Use o seu usuário e endereço SSH no comando em um PowerShell e deixe essa janela aberta.

ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:15678:127.0.0.1:5678 usuario@servidor

Em outro PowerShell, na pasta dos arquivos, rode o comando abaixo com Python 3 instalado. Então abra 127.0.0.1:8787 no navegador.

py -3 servidor.py
